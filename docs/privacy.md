# MenuHarbor 隐私说明

最后更新：2026-09-02

MenuHarbor 是本地菜单栏工具。它没有账号、分析 SDK、云同步或网络服务。

## 权限用途

### 屏幕录制

仅在你打开 Harbor Shelf 或菜单栏布局需要刷新时，读取系统菜单栏状态窗口的图像，用来显示图标预览。图像只在当前进程内存中短暂存在，未写入磁盘，也不会发送到网络。

### 辅助功能

当你点按 Shelf 里的某个图标时，MenuHarbor 临时展开原状态项并发送一次对应的鼠标点击，让原应用继续处理自己的菜单。它不会读取其他应用的文档、输入框或内容。

拒绝这两项权限不会影响基础折叠和手动展开。

## 本地数据

MenuHarbor 只在 `UserDefaults` 保存以下偏好：自动收起时间、按钮样式、快捷键开关、登录启动开关和引导完成状态。不会保存菜单栏截图、剪贴板、窗口内容或键盘记录。

## 撤销权限

前往“系统设置 → 隐私与安全性”，在“屏幕录制”或“辅助功能”中关闭 MenuHarbor。应用会在下一次打开 Shelf 时重新检测并降级，不会阻止你退出或恢复图标。
