# MenuHarbor 使用指南

> 给带刘海 Mac 的日常使用说明。MenuHarbor 的目标很简单：当菜单栏图标被刘海挤住、挡住，或者多到很难找到时，给你一个固定、容易记住的入口；点一下，就在刘海下方打开一个可以搜索和操作的图标港湾。

## 先理解它解决的是什么问题

Mac 的菜单栏是横向的一条窄空间。刘海占掉中间一段后，Wi‑Fi、VPN、云盘、输入法、即时通讯、会议工具等状态图标可能出现几种令人困惑的情况：

- 图标明明在运行，却被刘海遮住或挤到不可达的位置；
- 图标太多时，用户要在一条很窄的区域里反复寻找，甚至不知道该往哪边点；
- 为了腾位置而频繁按住 `⌘` 拖动图标，整理后又担心系统升级或换屏会改变布局；
- 只靠悬停或“记住它大概在哪”不可靠，尤其是在全屏应用、外接屏或临时接入 VPN 时。

MenuHarbor 的处理方式是“集中访问”，不是把每个第三方图标强行搬到一个新的物理位置：

1. 在菜单栏保留一个稳定的 **MenuHarbor 主按钮**，并在刘海屏下方提供一个可见的固定港湾入口；
2. 点击入口后，在菜单栏下方打开 **Shelf（港湾）**；
3. Shelf 集中展示当前屏幕上的菜单栏项目，把可能被刘海挡住的项目优先放在前面；
4. 通过搜索、键盘或点击直接找到目标，不需要猜原图标藏在哪里。

Shelf 是按需出现的浮层，不会一直盖住你的工作区。点击图标后它会关闭；失焦或按 `esc` 也会关闭。

## 最短使用路径：入口 → 港湾 → 找到图标

### 1. 找到固定入口

默认情况下，MenuHarbor 的图标在菜单栏右侧。主按钮在应用启动时最后创建，会尽量靠近系统控制中心；带刘海的屏幕还会在菜单栏下方显示一个小型 **港湾** 按钮，并显示当前图标数或可能溢出的数量。

如果菜单栏太拥挤，连主按钮都不容易看到，不需要重新整理菜单栏，直接使用下面任一种备用入口：

- 按默认快捷键 `⌃⌥H`；
- 鼠标停在刘海正下方的窄热区，或停在主按钮上约 0.25 秒；
- 在“设置 → 通用”打开“悬停区域扩展”后，把鼠标停在菜单栏右半侧；
- 如果你主动打开了“滚动切换”，在菜单栏上滚动一次。

这里的“固定”指入口会稳定地出现在刘海下方的同一位置，并且不会因为菜单栏图标变多而被挤走；它不是可以拖到屏幕任意位置的悬浮球。你也可以在“设置 → 通用”关闭这个入口。

### 2. 点一下，打开港湾

点击菜单栏主按钮、刘海下方的固定港湾入口或触发快捷键后，Shelf 会出现在菜单栏下方。它会针对**当前锚定屏幕**扫描菜单栏项目；接入多显示器时，不会把其他屏幕的同一份图标混进当前列表。

打开后你可以看到：

- 图标缩略图（开启屏幕录制权限后更接近原图标外观）；
- 图标名称和所属应用（开启辅助功能权限后名称更准确）；
- 橙色警示数字：可能被刘海或菜单栏溢出影响的项目数量；
- 收纳模式下，可能被挡住的项目会优先排列。

### 3. 搜索、选择、打开

- 在搜索框输入应用名或图标名，例如 `wifi`、`VPN`、`微信`；
- 搜索会忽略大小写、声调和全角差异，输入 `cafe` 可以找到 `Café`，全角 `ｗｉｆｉ` 也能找到 `WiFi`；
- 没有直接匹配时，会尝试按字符顺序模糊匹配，例如 `wfi` 也可能找到 `WiFi`；
- 搜索框为空时，按 `←` / `→` 移动选中项，按 `↩︎` 打开；
- 鼠标直接点击 Shelf 中的图标也可以打开它对应的原生菜单。

如果 Shelf 中出现橙色数字，先点击它可以切换到 **只看溢出**，优先处理最可能被刘海挡住的图标；再次点击恢复全部结果。输入搜索词后，数字只统计当前搜索结果中的溢出项目。

## 五种入口，按场景选择

| 入口 | 适合什么时候用 | 说明 |
|---|---|---|
| 主按钮 | 日常使用 | 最直观。点击后打开 Shelf，再搜索或点击目标图标。 |
| 快捷键 | 主按钮被挤掉、全屏工作、手不想离开键盘 | 默认 `⌃⌥H`，可在设置中重新录制；如果注册失败，会提示可能存在快捷键冲突。 |
| 刘海下方热区 | 想用鼠标，但不想在菜单栏里找按钮 | 开启“悬停展开”后，鼠标停留约 0.25 秒即可打开；移开后约 0.7 秒收起。 |
| 右半菜单栏热区 | 图标很多，主按钮位置不容易发现 | 在“设置 → 通用”开启“悬停区域扩展”；只覆盖菜单栏右半侧，避免经过左侧应用菜单时误触。 |
| 滚动切换 | 经常在菜单栏上操作，喜欢手势 | 默认关闭。在“设置 → 通用”开启后，在菜单栏滚动可触发主入口动作。 |

悬停打开时不会抢走当前输入焦点；需要键盘搜索时，仍建议用主按钮或快捷键打开。

## 系统会自动选择工作模式

你不需要先判断自己的 macOS 是否支持折叠。MenuHarbor 会自动探测：

### 刘海安全 / 收纳模式（带刘海的屏幕、macOS 26+）

系统会回收或重新布局被折叠的状态项，因此 MenuHarbor 不强行把图标推到一个可能失效的折叠区，而是保持原生菜单栏稳定，扫描当前屏幕的图标并在 Shelf 中集中展示。这个模式最适合解决“我知道图标在运行，但刘海挡住了它”的问题。

### 折叠模式（无刘海且系统支持）

可以把不常用图标放进隐藏区或始终隐藏区，像传统菜单栏管理器一样折叠起来。Shelf 仍然是访问这些图标的固定入口。展开、收起和整理不会改变应用自己的菜单内容。

在“设置 → 通用”顶部可以看到当前模式。若系统行为改变导致折叠不可靠，MenuHarbor 会自动转为收纳模式，并提供“立即恢复”出口。

## 第一次使用与推荐设置

1. 首次启动按引导完成基础设置；带刘海的 Mac 不需要逐个拖图标。
2. 建议保留“刘海固定入口”，它是最容易发现的鼠标入口，不依赖菜单栏还有多少空间。
3. 建议在“设置 → 通用”保留“悬停展开”，适合想快速唤出 Shelf 的场景。
4. 建议确认快捷键已开启。它是主按钮或浮动入口暂时不可用时最可靠的备用入口。
5. 如果菜单栏项目很多，可开启“悬停区域扩展”，但不建议同时依赖过于敏感的手势；以快捷键作为明确的兜底。
6. 想让每次开机都能使用，在“登录时启动”打开后无需手动运行应用。
7. 通过“按钮样式”选择更醒目的港湾符号或更低调的圆点。

## 权限怎么选

基础收纳、入口和 Shelf 列表不依赖授权。两项增强权限都只在本机使用：

| 权限 | 用途 | 未开启时的体验 |
|---|---|---|
| 屏幕录制 | 读取菜单栏窗口的外观，为 Shelf 生成更接近真实状态的缩略图 | 仍可看到列表和名称，但缩略图可能使用通用应用图标；不会保存截图。 |
| 辅助功能 | 读取更准确的状态项名称，并尝试通过语义按压代你点击原生图标 | 仍可搜索；点击失败时会退回原生菜单栏手动点击。 |

在“设置 → 权限与隐私”点击“开启”即可跳到系统设置。授权完成后页面会自动刷新，不需要重启 MenuHarbor。

## 典型场景

### VPN、云盘或会议工具刚刚启动

不用重排菜单栏。打开 Shelf，等待短暂同步，直接搜索应用名；Shelf 打开期间会持续刷新菜单栏变化。

### 刘海正好挡住了目标图标

按 `⌃⌥H` 或把鼠标停在刘海下方，打开 Shelf；点橙色数字切到“只看溢出”，然后搜索或点击目标。

### 外接显示器

先把鼠标或 MenuHarbor 主按钮放在目标屏幕上，再打开 Shelf。列表会锚定当前屏幕，避免把另一块屏幕的同名图标混在一起。

### 不想用鼠标

按快捷键 → 输入搜索词 → 用 `←` / `→` 选择 → 按 `↩︎` 打开 → 按 `esc` 关闭。

## 点击没有打开时怎么办

MenuHarbor 不会把“事件已发送”误报成“目标菜单一定已打开”。某些第三方应用不暴露可按压的辅助功能元素，或系统布局在瞬间发生变化时，直接代点击可能失败。此时：

1. 先确认目标图标仍在 Shelf 中；
2. 如果提示“无法代为点击”，回到原生菜单栏手动点击；
3. 折叠模式下，应用会先安全展开菜单栏再给出手动点击退路；
4. 收纳模式下不会为了点击而强行改变原生布局。

## 设置项速查

| 设置 | 作用 |
|---|---|
| 自动收起 | 折叠模式下，展开后无操作多久恢复隐藏：关闭、5 秒、10 秒或 30 秒。 |
| 快捷键 | 录制并启用打开港湾的组合键；默认 `⌃⌥H`。 |
| 悬停展开 | 主按钮或刘海下方热区停留后自动打开。 |
| 刘海固定入口 | 在带刘海的屏幕下方显示固定港湾按钮；默认开启，可手动关闭。 |
| 悬停区域扩展 | 把菜单栏右半侧加入鼠标入口。需先开启悬停展开。 |
| 滚动切换 | 在菜单栏上滚动触发主入口动作，默认关闭。 |
| 登录时启动 | 登录后自动运行 MenuHarbor。 |
| 按钮样式 | 港湾符号或低调圆点。 |
| 恢复全部图标 | 折叠模式进入整理模式，让隐藏区和始终隐藏区的图标全部出现。 |

## 故障排查

| 现象 | 处理 |
|---|---|
| 菜单栏找不到 MenuHarbor 图标 | 直接按 `⌃⌥H`，或把鼠标停在刘海下方热区；也可临时开启“悬停区域扩展”。 |
| 收起后很快又展开 | 当前系统可能不支持可靠折叠，MenuHarbor 已自动切到收纳模式，这是保护行为。 |
| Shelf 里名称像 `Item-0` | 在“权限与隐私”开启辅助功能，MenuHarbor 才能读取更准确的状态项名称。 |
| 缩略图不是真实图标 | 开启屏幕录制权限；该权限只用于内存中的短暂读取。 |
| 快捷键没反应 | 在设置里重新录制组合；其他应用可能已经占用原组合。 |
| 搜索不到刚启动的应用 | 等待 Shelf 自动同步，或在空列表状态点击“重新扫描”。 |
| 想退出并恢复系统原样 | 右键 MenuHarbor 主按钮 → “退出 MenuHarbor”。退出前会恢复原生菜单栏状态。 |

## 隐私与能力边界

- MenuHarbor 不联网、不需要账号、不上传截图，也没有统计 SDK。
- 菜单栏截图只在内存中短暂处理，不保存到磁盘；偏好设置保存在本机 `UserDefaults`。
- macOS 没有公开 API 能保证枚举、复制和点击所有第三方 `NSStatusItem`。因此个别应用可能只能显示名称、需要手动点击，或在系统升级后行为变化。
- “可能被刘海挡住”是基于窗口位置和屏幕安全区域的判断，不等同于对每个图标都做了系统级可见性保证。
- 每个显示器只展示当前锚定屏幕的一份图标；切换显示器或显示器布局变化时，当前 Shelf 会关闭，重新打开即可获得新列表。

## 一句话记忆

**不要在刘海两边猜图标在哪里：找到 MenuHarbor 的固定入口（看得到就点，看不到就按 `⌃⌥H`），打开港湾，搜索并点击。**
