# MenuHarbor 使用指南

> 面向使用者的操作手册。构建方式见 [README](../README.md)。

## 你的机器当前是什么模式？

MenuHarbor 会自动探测系统能力，你不需要选：

| 模式 | 适用系统 | 行为 |
|---|---|---|
| **折叠模式** | macOS 14 / 15 | 完整三区管理：可以把图标折叠隐藏 |
| **收纳模式** | macOS 26+（你的机器） | 系统会强制回收被折叠的图标（同类产品 Ice/Hidden Bar 全部失效），因此自动保持菜单栏原生布局，港湾转为**展示、搜索、点击全部菜单栏图标** |

可以在 **设置 → 通用** 顶部看到当前模式的状态提示。收纳模式下一切全自动，无需整理菜单栏。

## 一分钟上手

1. 菜单栏右侧找到**港湾图标**（一个"下半填充的托盘"形状；如果图标多，它可能在刘海附近——这正是本工具要解决的问题）。
2. **点它** → 港湾 Shelf 在菜单栏下方弹出，展示全部菜单栏图标。
3. **输入关键字**（如 "wifi"、"微信"）即时过滤；`←`/`→` 选择，`↩︎` 打开，`esc` 关闭。
4. 如果顶部出现橙色数字，点它可切到**只看溢出**，先处理可能被刘海挡住的图标；再次点击可恢复全部。
5. 点击 Shelf 里的图标 = 代你在菜单栏点击它（需要辅助功能权限，见下文权限说明）。

## 打开港湾的 4 种方式

| 方式 | 说明 | 开关位置 |
|---|---|---|
| 点击主按钮 | 默认开启 | — |
| 快捷键 | 默认 `⌃⌥H`，可在设置中录制任意组合 | 设置 → 快捷键 |
| 悬停 | 鼠标在主按钮/刘海下方停留 0.25 秒自动打开，移开自动收起 | 设置 → 悬停展开 |
| 悬停区域扩展 | 悬停**菜单栏右半侧**任意位置即打开（iBar 式入口），需先开悬停 | 设置 → 悬停区域扩展 |
| 滚动 | 在菜单栏上滚动滚轮切换 | 设置 → 滚动切换（默认关） |

Shelf 打开后：**失焦自动关闭**；`esc` 手动关闭。

## 权限说明（重要）

基础功能免授权。两项增强权限都在**本机**使用，不上传任何数据：

| 权限 | 作用 | 没有它会怎样 |
|---|---|---|
| 屏幕录制 | 截取菜单栏图标，在 Shelf 中显示**真实图标外观** | 图标显示为通用应用图标 |
| 辅助功能 | ① 读取图标的**真实名称**（如"WiFi""飞书"，否则显示系统内部名）② **代你点击**原图标 | 名称显示不全；点击 Shelf 图标会退回"展开菜单栏手动点" |

**建议：在 设置 → 权限与隐私 中开启两项**，尤其是辅助功能——macOS 26 下图标名内部标记全是"Item-0"，开启后 Shelf 才能按真实名称搜索。

- 点设置里的"开启"会弹出系统授权窗口
- 授权完成后设置页会**自动刷新**状态，无需重启
- 如果授权后状态没变：系统设置 → 隐私与安全性 → 对应列表里确认开关已打开

## 折叠模式专用（macOS 14/15）

1. 右键港湾图标 → **整理模式（显示全部）**，两个分隔标记都会出现
2. 按住 `⌘` 拖动图标：
   - 拖到 **双箭头 «** 左侧 → 进入隐藏区
   - 拖到最左 **竖线 ⊢** 左侧 → 始终隐藏（展开菜单栏时也保持隐藏，只在港湾出现，带圆钉标记）
3. 点双箭头收起。收起状态下点港湾图标即可在刘海下方访问它们
4. 自动收起：展开后无操作 5/10/30 秒自动折叠（设置可调；按住 ⌘ 拖拽时不会打断你）

## 设置项速查

| 设置 | 作用 |
|---|---|
| 自动收起 | 展开后无操作多久恢复折叠（关/5/10/30 秒） |
| 快捷键 | 点击"⌃⌥H"按钮 → 按下新组合 → 即刻生效；旁边开关控制启用 |
| 悬停展开 / 区域扩展 | 见上表 |
| 滚动切换 | 菜单栏上滚动滚轮切换 |
| 登录时启动 | 开机自动运行 |
| 按钮样式 | 港湾符号 / 低调圆点 |
| 恢复全部图标 | 进入整理模式，全部图标+分隔标记可见，方便重新布置 |

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 收起后 1-2 秒又自动展开了 | 你的系统是 macOS 26+，系统不支持折叠。这是**自动保护**（避免图标丢失），已转入收纳模式，属预期行为 |
| Shelf 里图标名显示 "Control C..." | 未开辅助功能权限。开启后显示真实名称（见权限说明） |
| 菜单栏找不到港湾图标 | 图标太多被刘海挤掉了——这正是本工具解决的问题；用快捷键 `⌃⌥H` 或悬停刘海下方热区打开港湾 |
| 快捷键没反应 | 可能与其他 app 冲突，设置里录制一个新组合 |
| 想彻底退出 | 右键港湾图标 → 退出 MenuHarbor；退出前会自动恢复菜单栏原生状态 |

## 隐私

不联网、无账号、无统计。所有数据只存在本机 UserDefaults。权限用途见上表，截图只在内存中短暂处理，不保存。

## 已知边界

- macOS 26+ 折叠被系统禁用（系统行为，非 bug），收纳模式是官方推荐的替代形态
- 每个显示器菜单栏上的图标副本只显示锚定屏的一份
- 代点击依赖辅助功能权限与系统事件转发，个别应用的图标可能点不动，此时会自动展开菜单栏让你手动点击
