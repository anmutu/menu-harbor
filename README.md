# MenuHarbor

MenuHarbor 是一个原生 macOS 菜单栏溢出层：**刘海挡住的菜单栏图标，自动集中到刘海下方的港湾，点一下仍能用，同时保持原生菜单栏稳定。**

## 现在能做什么

- **刘海安全模式（带刘海的屏幕自动启用）**：不需要逐个按住 ⌘ 拖图标，港湾会扫描当前屏幕的菜单栏图标，在刘海下方展示并支持搜索。
- **收纳模式（macOS 26+ 自动启用）**：系统会回收被折叠的图标时，自动保持菜单栏原生布局，港湾转为展示、搜索全部菜单栏图标并支持代点击；有辅助功能权限时显示图标的真实名称。
- 无刘海屏幕仍可使用三区管理（Ice 式）：可见图标、隐藏区（双箭头分隔标记左侧）、始终隐藏区（最左竖线标记左侧）。
- 点 MenuHarbor 主按钮、快捷键或可选滚动手势，在菜单栏下方打开安全的 Harbor Shelf。
- Shelf 打开期间会自动同步菜单栏变化；疑似被刘海/溢出遮挡的项目会优先排列并用警示标记提示。
- 有屏幕录制权限时显示真实图标快照；没有权限时仍可看到应用名称并展开原生菜单栏。
- 有辅助功能权限时，代点击走辅助功能语义按压（AXPress），比合成坐标点击更可靠；始终隐藏区的图标会在点击前临时完全恢复。权限不足时自动退回手动展开。
- 搜索、可录制快捷键、5/10/30 秒自动收起、登录启动、浅色/深色材质。
- 港湾内可用键盘操作：搜索框自动聚焦，搜索词为空时 `←`/`→` 在图标间移动、`↩︎` 打开、`esc` 关闭；始终隐藏图标带圆钉标记。
- 悬停展开（可选，默认开启）：鼠标在主按钮或刘海下方热区上短暂停留即打开港湾，移开后自动收起，不打断当前输入。
- 滚动切换（可选，默认关闭）：在菜单栏上滚动滚轮即可收起或展开。
- 港湾失焦即自动关闭；按住 ⌘ 拖拽整理图标、或港湾正打开时，自动收起会主动让路。
- **折叠健康自检**：收起后自动验证图标真的离开了屏幕；系统布局行为变化导致折叠失效时，设置页会明确警告并提供恢复出口（macOS 26 已确认影响同类产品）。
- 右键主按钮可进入“整理模式（显示全部）”，两个分隔标记都可见，方便重新布置。
- 引导和设置窗口打开时实时追踪权限状态，授权回来后无需重启。
- 所有数据留在本机，不联网、不需要账号、不上传截图。

## 构建与运行

需要 macOS 14+、Xcode Command Line Tools 和 Swift 6.2+：

```bash
make test
make app
open .build/release/MenuHarbor.app
```

首次运行会显示三步引导。基础折叠无需授权；Shelf 的图标外观和代点击能力会分别请求屏幕录制、辅助功能权限。

## 第一次使用

1. 带刘海的屏幕：直接点击 MenuHarbor 图标或使用快捷键，港湾会自动列出当前屏幕的菜单栏图标。
2. 如果需要在港湾内直接点击图标，按提示开启辅助功能；屏幕录制权限只用于显示真实图标快照。
3. 无刘海屏幕：右键点 MenuHarbor 图标，选“整理模式（显示全部）”，再按住 `⌘` 把图标拖到双箭头分隔标记左侧；始终隐藏区使用最左侧竖线标记。

如果系统版本改变了菜单栏布局行为，可以随时在设置中点“立即恢复”，或退出 MenuHarbor；退出前应用也会自动展开分隔区。

## 已知边界

macOS 没有公开 API 用来枚举、复制和点击所有第三方 `NSStatusItem`。因此 MenuHarbor 使用系统状态窗口信息和可选的辅助功能/截图权限来增强体验，不能承诺每一个第三方项目在每个系统版本都可直接点击。增强能力失效时，应用始终提供原生展开退路。

这个项目是官网/Developer ID 分发取向的 MVP，不承诺 Mac App Store 审核通过。菜单栏相关系统行为可能随 macOS 升级变化，基础折叠和恢复逻辑会优先保持可用。
