被刘海藏起来的
每一个图标，都该有港可停。

MacBook 的刘海越来越宽，菜单栏的图标越来越多。二者相遇时，总有一些图标被挤出屏幕，再也点不到。MenuHarbor 在刘海下方修了一座港湾——被挡住的图标自动停靠于此，能看、能搜、也能直接点；原生菜单栏保持原样，不动声色。

其一

它做什么

FEATURES

不必逐个按住 ⌘ 拖图标，也不必记住哪一项藏到了哪里。MenuHarbor 只专注一件事：让每一个菜单栏图标都可达。以下九则，按使用频度排列。

一

刘海安全

带刘海的屏幕自动启用。扫描当前屏幕的菜单栏图标，集中到刘海下方展示，无需手动整理。

二

固定港湾入口

刘海下方常驻一枚「港湾」按钮，不会被菜单栏挤掉，且带溢出计数；点它即达。

三

收纳模式

macOS 26 起系统会回收被折叠的图标，同类产品尽数失效。MenuHarbor 自动转入收纳模式：菜单栏保持原生，港湾照常可用。

四

容错搜索

大小写、声调与全角自动折叠——cafe 寻得 Café，全角 ｗｉｆｉ 等同 wifi；无精确命中时按字序模糊匹配，wfi 亦能寻得 WiFi。

五

可靠代点击

开启辅助功能后，点港湾里的图标即走语义按压（AXPress）直达原生菜单项；权限不足时体面退回手动展开。

六

三区管理

无刘海屏幕可用经典三区：可见、隐藏、始终隐藏。按住 ⌘ 拖拽布置，一次整理，长期有效。

七

折叠健康自检

收起后自动验证图标真的离开了屏幕；系统行为有变则明确警告，并给出一键恢复，不让图标无声失踪。

八

键盘优先

打开即聚焦搜索，←→ 选择、↩ 打开、esc 关闭；快捷键默认 ⌃⌥H，可录制任意组合。

九

隐私本地

不联网、无账号、无统计。截图只在内存中短暂处理；全部偏好存于本机。

如何得到

第一步

下载解压

自 GitHub Releases 取最新压缩包，解压出 MenuHarbor.app，移入「应用程序」。

第二步

首次打开

在访达中对应用右键 → 打开（缘由见下方附注）。首启有三步引导。

第三步

按需授权

基础收纳不必授权；屏幕录制显示真实图标，辅助功能用以直接点击。

※附注：应用目前使用临时签名（尚未购入 Apple Developer ID），Gatekeeper 或于首次打开时拦问。右键选「打开」，或往 系统设置 → 隐私与安全性 点「仍要打开」即可；亦可克隆仓库以 make app 自行构建。下载地址：GitHub Releases ↗

其三

两个可选的权限

PRIVACY

屏幕录制 可选

截取菜单栏图标本身，在港湾里显示真实外观。图像只在内存中短暂处理，不写盘、不上传。

辅助功能 可选

读取图标的公开名称（否则 macOS 26 下只见 Item-0），并代你对原图标执行一次语义按压。
