为什么是 MenuHarbor

专注解决一个问题：让每一个菜单栏图标都可达。

🖥

刘海安全模式

带刘海的屏幕自动启用。扫描当前屏幕的菜单栏图标，集中到刘海下方展示，不需要逐个 ⌘ 拖拽整理。

📍

固定港湾入口

刘海下方常驻一个不会被挤掉的「港湾」按钮，带溢出计数；主按钮、快捷键、悬停、滚动同样可以打开。

🧭

收纳模式

macOS 26 起系统会回收被折叠的图标（同类产品全部失效）。MenuHarbor 自动检测并转入收纳模式：菜单栏保持原生，港湾照常可用。

🔍

容错搜索

大小写、声调符号与全角字符自动折叠——cafe 找到 Café、全角 ｗｉｆｉ 等同 wifi；无精确命中时按字符顺序模糊匹配，wfi 也能找到 WiFi。

👆

可靠代点击

开启辅助功能后，点港湾里的图标会走语义按压（AXPress）直达原生菜单项，比合成坐标点击更可靠；权限不足自动退回手动展开。

🗂

三区管理

无刘海屏幕可用经典三区：可见、隐藏（双箭头左侧）、始终隐藏（竖线左侧）。按住 ⌘ 拖拽布置，一次整理长期有效。

🩺

折叠健康自检

收起后自动验证图标真的离开屏幕；系统布局行为变化导致折叠失效时，明确警告并提供一键恢复，不让图标无声丢失。

⌨️

键盘优先

打开即聚焦搜索框，←→ 选择、↩︎ 打开、esc 关闭；快捷键默认 ⌃⌥H，可录制任意组合。

🔒

隐私本地

不联网、无账号、无统计。截图只在内存中短暂处理；所有偏好存在本机 UserDefaults。

前往 GitHub Releases
1下载解压

从 GitHub Releases 下载最新压缩包，解压出 MenuHarbor.app，拖入「应用程序」文件夹。

2首次打开

在访达中右键 → 打开再点「打开」（见下方说明）。首次运行有三步引导。

3按需授权

基础收纳不需要任何权限；开启屏幕录制显示真实图标，开启辅助功能可直接点击。

⚠️ MenuHarbor 目前使用临时签名（未购买 Apple Developer ID）。macOS Gatekeeper 可能拦截首次打开：请右键点击应用选「打开」，或到 系统设置 → 隐私与安全性 中点「仍要打开」。也可以 make app 从源码自行构建。

权限与隐私

基础功能免授权。两项可选权限都在本机使用。

📸

屏幕录制（可选）

截取菜单栏图标本身，在港湾里显示真实外观。图像只在内存中短暂处理，不写盘、不上传。

♿️

辅助功能（可选）

读取图标的公开名称（否则 macOS 26 下只显示 Item-0），并代你对原图标执行一次语义按压。
