它做什么

每一个图标，都触手可及

不必逐个按住 ⌘ 拖图标，也不必记住哪一项藏到了哪里。

刘海安全

带刘海的屏幕自动启用：扫描菜单栏图标，集中到刘海下方展示，无需手动整理。

固定港湾入口

刘海下方常驻一枚「港湾」按钮，不会被菜单栏挤掉，带溢出计数，点它即达。

收纳模式

macOS 26 起系统回收被折叠的图标，同类产品尽数失效。MenuHarbor 自动切换：菜单栏保持原生，港湾照常可用。

容错搜索

大小写、声调与全角自动折叠——cafe 找到 Café；无精确命中时模糊匹配，wfi 也能找到 WiFi。

可靠代点击

开启辅助功能后，点港湾里的图标即走语义按压（AXPress）直达原生菜单项；权限不足时体面退回手动展开。

三区管理

无刘海屏幕可用经典三区：可见、隐藏、始终隐藏。⌘ 拖拽布置，一次整理长期有效。

折叠健康自检

收起后验证图标真的离屏；系统行为有变则明确警告、一键恢复，不让图标无声失踪。

键盘优先

打开即聚焦搜索，←→ 选择、↩ 打开、esc 关闭；快捷键默认 ⌃⌥H，可录制任意组合。

隐私本地

不联网、无账号、无统计。截图只在内存中短暂处理，全部偏好存于本机。

开始使用

三步，把图标停进港湾

下载解压

从 GitHub Releases 取最新压缩包，解压出 MenuHarbor.app，移入「应用程序」。

2

首次打开

在访达中对应用右键 → 打开（缘由见下方提示）。首次运行有三步引导。

3

按需授权

基础收纳不必授权；屏幕录制显示真实图标，辅助功能用以直接点击。

应用目前使用临时签名（尚未购入 Apple Developer ID），Gatekeeper 可能于首次打开时拦问：右键选「打开」，或到 系统设置 → 隐私与安全性 点「仍要打开」即可；也可克隆仓库以 make app 自行构建。下载地址：GitHub Releases
权限与隐私

权限最少，数据不出本机

基础功能免授权。两项可选权限都在本机使用。

屏幕录制 · 可选

截取菜单栏图标本身，在港湾里显示真实外观。图像只在内存中短暂处理，不写盘、不上传。

辅助功能 · 可选

读取图标的公开名称（否则 macOS 26 下只见 Item-0），并代你对原图标执行一次语义按压。
