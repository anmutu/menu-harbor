Icons the notch might block (▲) come first · Forgiving search — "wfi" still finds WiFi

Every MacBook owner has a few icons
they can never click again.

MenuHarbor started with three small things.

i.

Vanish

Icons disappear quietly. Install a new app and its icon appears on the right of the menu bar; install another and everything shuffles left. One day you go looking for it — it's behind the notch. The system still knows it's there; you just can't click it anymore.

ii.

Struggle

The old fix was to hold ⌘ and drag rarely-used icons past a separator. Then macOS 26 arrived and the system began reclaiming folded icons — breaking that trick, and a generation of menu bar tools with it.

iii.

Dock

MenuHarbor took another path: don't fight the system — build a harbor below the notch. Displaced icons dock there automatically: visible, searchable, clickable. The native menu bar stays exactly as it was.

What it does

Every icon, back within reach

No ⌘-dragging icons one by one, no remembering where things went.

Notch-safe

Engages automatically on notched screens: menu bar icons are scanned and gathered right below the notch. No manual sorting required.

Fixed harbor entry

A "Harbor" button lives just below the notch and can't be pushed off the bar, with a live overflow count. One click opens the shelf.

Collect mode

macOS 26 reclaims folded icons, which breaks classic folding tools. MenuHarbor switches automatically: the menu bar stays native and the harbor keeps working.

Forgiving search

Case, accents and full-width characters fold automatically — cafe finds Café; with no exact match, fuzzy matching kicks in, so wfi still finds WiFi.

Reliable click-through

With Accessibility enabled, clicking an icon in the harbor issues a semantic press (AXPress) on the original item; without it, MenuHarbor falls back gracefully to expanding the menu bar.

Three-zone layout

On notch-free screens use the classic three zones: visible, hidden, always hidden. Arrange once with ⌘-drag and it sticks.

Fold health check

After collapsing, MenuHarbor verifies the icons really left the screen; if system behavior changes, it warns you and offers one-click restore.

Keyboard first

Search is focused on open: ←→ to select, ↩ to open, esc to close. Default shortcut ⌃⌥H; record any combination.

Private by design

No network, no accounts, no analytics. Snapshots live only in memory; every preference stays on your Mac.

Permissions & privacy

Minimum permissions, nothing leaves your Mac

Core features need no authorization. Two optional permissions, both local-only.

Screen Recording · optional

Captures the menu bar icons themselves so the harbor shows their real look. Images are processed briefly in memory — never written to disk, never uploaded.

Accessibility · optional

Reads public icon names (otherwise macOS 26 shows only Item-0) and performs one semantic press on the original icon for you.

No network · No accounts · No analytics — full details in privacy.md

FAQ

You might ask

macOS 26 reclaims folded menu bar icons and breaks folding tools — what then?

Starting with macOS 26 the system reclaims folded menu bar icons, which breaks the folding approach used by Bartender, Ice and Hidden Bar. MenuHarbor ships with a fold health check; when it detects this behavior it automatically switches to collect mode: the menu bar keeps its native layout while the harbor continues to show, search, and click every icon.

Is there a free, open-source alternative to Bartender and Ice?

MenuHarbor is open source (MIT), free, and subscription-free: notch-safe mode, forgiving search, click-through, and three-zone management in one package. Grab the universal build from GitHub Releases — it runs on both Apple Silicon and Intel.

The notch is hiding my menu bar icons — how do I get them back?

On a notched Mac, MenuHarbor automatically enters notch-safe mode: hidden icons dock into the harbor Shelf below the notch, sorted first and flagged with a warning mark, searchable and directly clickable. A permanent "Harbor" button sits just below the notch, so the entry point can never be pushed away.

Does MenuHarbor upload any data?

No. No network connections, no accounts, no analytics; snapshots are processed briefly in memory and preferences stay on your Mac. Screen Recording and Accessibility are both optional — declining either doesn't affect basic collecting.
